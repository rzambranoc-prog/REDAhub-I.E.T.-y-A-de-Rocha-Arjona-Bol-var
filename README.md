# REDAhub-I.E.T.-y-A-de-Rocha-Arjona-Bolivar
Ecosistema pedagógico integral para la enseñanza y el aprendizaje de los números fraccionarios en los grados 3°, 4° y 5° de básica primaria de la I.E.T. y A del corregimiento de Rocha, muni-cipio de Arjona, departamento de Bolívar.
